# AirGlide

Created by Aditya Krishna Thota · [@adi__krish](https://www.instagram.com/adi__krish/)

Use your Android phone or iPhone as a motion pointer for your Windows PC, similar to an air mouse.

AirGlide is an installable Android and iPhone web app with a portable Windows companion. No Mac, Apple developer membership, Node.js, Python, or account is needed to run the included Windows build. It is not an App Store app or a signed IPA.

## Android quick start

1. Run START.cmd on Windows and leave the console open. Connect the Android phone and PC to the same home network.
2. Scan the First time? QR code, open in Chrome and choose Android.
3. Download AirGlide-Local.crt. Compare its certificate fingerprint against the Windows dashboard. In Android Settings find Install a certificate, choose CA certificate and install the downloaded file.
4. Return to Chrome, tap Open AirGlide and enter the current six-digit code.
5. Enable motion and aim the phone’s top edge at the monitor. Use Touchpad if sensor readings are unavailable. Keep the app visible during use.
6. Use Chrome’s Install app or Add to Home screen option to add the Telugu icon.

To uninstall, remove the app or Home screen shortcut and remove the specific AirGlide certificate in Android Settings. Motion sensor behavior depends on the device. Android hardware testing is pending.

## iPhone quick start

1. Download the ZIP on your **Windows PC**. Right-click it and choose **Extract All**.
2. Open the extracted folder and double-click **START.cmd**. Keep its console window open. A setup page opens in your PC's browser.
3. Connect your iPhone to the **same home network**. The PC can use Wi-Fi or Ethernet.
4. On the iPhone, scan the **First time?** QR code with the Camera app and open the link in Safari.
5. Follow the certificate steps below. Then open AirGlide and enter the **six-digit code shown on the PC**.
6. In Safari, use **Share → Add to Home Screen**. Enable **Open as Web App** if shown. Open AirGlide from its new icon. If asked, enter the PC code again.
7. Tap **Enable motion**, allow Motion & Orientation access, and aim the phone's top edge toward the monitor. Small wrist movements move the cursor.

Allow access to your local network if iOS asks. On Windows, allow the companion on your **private home network** if prompted.

## One-time iPhone certificate setup

Safari requires a trusted HTTPS connection for motion access. The Windows companion creates a certificate specifically for its local connection.

1. On the iPhone setup page, tap **Download certificate profile**.
2. Open **Settings → Profile Downloaded → Install**. If the shortcut is missing, open **Settings → General → VPN & Device Management**.
3. Use the certificate name shown on the PC dashboard. Existing installations can keep their previously trusted certificate. It contains only a certificate; it does not enroll the phone in device management or add a VPN.
4. Open **Settings → General → About → Certificate Trust Settings** and turn on trust for that exact certificate.
5. Return to Safari and tap **Open AirGlide**.

Install only the profile generated by your own PC. The setup page and PC dashboard show the certificate's SHA-256 fingerprint so you can compare them. A root certificate is a sensitive trust setting. The companion discards the root signing key after issuing its server certificate; it keeps only the local server's private key. Remove the profile when you stop using AirGlide.

If Safari says the connection is not private, return to these steps and check the matching certificate, trust switch, phone date/time, and current PC address. Do not rely on bypassing the browser warning for sensor access.

## Controls

| Control | Action |
| --- | --- |
| Turn phone left/right; raise/lower its top edge | Move the Windows cursor |
| Large Click button | Left click; tap twice for a double click |
| Right click | Open the Windows context menu |
| Scroll strip | Swipe up/down to scroll |
| Hold to reposition | Pause pointer movement while adjusting your grip |
| Touchpad mode | Move with one finger; tap to click; use two fingers to scroll |
| Media row | Mute, volume down/up, play/pause, Escape |
| Keyboard | Send text to the active PC field, Enter, Backspace, Tab, Escape, arrows |
| Settings | Pointer speed, smoothing, reverse either axis, pause, disconnect |

Keep the phone in portrait and aim its **top edge** toward the monitor, like a remote. Avoid pointing it straight at the ceiling. Use Settings to adjust speed and direction for your preferred grip. The app uses relative motion, so it does not need a camera or a marker on your monitor.

Text is sent to whichever window has focus on Windows. Click the intended text field first. The app sends button presses; it does not read the PC screen or know the current player state.

## Daily use

Run START.cmd on your PC and open AirGlide on the iPhone. Pair using the current code when asked. The code changes each time the companion restarts; sessions also expire after 12 hours.

Keep the iPhone app visible. Switching apps or locking the phone pauses motion. Return to AirGlide and tap Enable motion again. Supported browsers are asked to keep the display awake, but iOS settings may still let the display sleep.

Only one remote controls the PC at a time. A second connection takes over and disconnects the previous one. Close the PC companion window to stop control immediately and invalidate all pairings.

## If the phone cannot connect

- Confirm the PC companion is still running and both devices use the same home network.
- Use the current QR code; a remembered IP address may be stale.
- In the PC dashboard, expand **Connection details**. If the PC has several network adapters, select the address belonging to your home Wi-Fi/Ethernet connection.
- Guest Wi-Fi, VPNs, or router client isolation can prevent devices from reaching each other.
- Check that Windows labels your trusted home connection **Private**.
- If the Windows firewall is blocking the app, right-click **Enable-Private-Network.cmd → Run as administrator**. This optional helper permits only this executable's TCP ports 43110 and 43111, on the Private profile, from the local subnet. It does not disable the firewall or change your network category.
- If the PC's IP address changes, restart the companion. It may create a new certificate. Repeat certificate setup on the iPhone and remove the old AirGlide profile.

The portable executable is an unsigned personal prototype. Windows may show an unknown-publisher or reputation warning. The source and executable checksum are included for inspection. Do not disable antivirus to run it.

## Limits of this build

- Intended for 64-bit Intel/AMD Windows PCs, including your Intel systems.
- Windows must be awake and logged in. This build does not power on or wake the PC.
- Windows lock screens, UAC secure-desktop prompts, and apps running at a higher privilege level cannot be controlled by this normal-user companion.
- The iPhone app must remain open. It does not provide background motion control.
- The connection is local IPv4 on a private network. There is no internet relay, Bluetooth transport, screen mirroring, voice control, or remote command shell.
- No drag-and-drop / held mouse button or multi-key shortcut mode in this first version.
- Certificate lifetime is 180 days for the server; the companion renews when necessary. A renewal or address change can require repeating the phone certificate steps.
- Software tests and browser layout checks are included. Physical iPhone sensor behavior and actual Windows SendInput execution have **not** been tested in this Linux build environment. First use on your devices is the remaining hardware check.

## Remove it

1. Close the companion window.
2. Delete the AirGlide icon from the iPhone Home Screen.
3. On iPhone, remove the AirGlide Local profile under **Settings → General → VPN & Device Management**.
4. Delete the extracted Windows app folder. Its local certificate files can also be removed from **%APPDATA%\AirRemote**.
5. If you used the optional firewall helper, remove the **AirGlide - private local network** rule in Windows Defender Firewall with Advanced Security. The helper also prints its exact PowerShell removal command.

## Source and rebuilding

The complete source is in the **source** folder. It uses Go for the Windows companion and plain JavaScript/HTML/CSS for the phone. Dependencies are vendored so a rebuild requires only a Go toolchain.

From the source folder on 64-bit Windows, with Go 1.24 or newer installed:

    go test ./...
    go build -buildvcs=false -trimpath -ldflags="-s -w" -o AirGlide.exe .

From Linux/macOS, cross-compile for Windows:

    GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -buildvcs=false -trimpath -ldflags="-s -w" -o AirGlide.exe .

Motion-math tests require Node.js:

    node --test tests/motion.test.js

The executable embeds all web assets. Rebuild after changing files in web/. A non-Windows build is deliberately an input simulator and visibly labels itself as such.

The transport allows only enumerated input actions. Pairing uses a random six-digit code, an attempt limit, Secure/HttpOnly/SameSite cookies, same-origin checks, local-address host validation, and encrypted WebSockets. No arbitrary program-launch or shell-command endpoint exists. TLS private keys are generated on the user's PC and are not included in this ZIP.
