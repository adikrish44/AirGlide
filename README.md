# AirGlide

Use an iPhone or Android phone as a motion pointer or touchpad for a Windows PC.

## Download and pair

1. [Download AirGlide for Windows](https://github.com/Adikrish44/AirGlide/releases/latest/download/AirGlide-Windows.zip) and extract the ZIP on a 64-bit Intel or AMD Windows PC.
2. Connect the phone and PC to the same trusted home network. Ethernet works for the PC.
3. Double-click `START.cmd` and keep the companion window open.
4. Scan **Pair a phone** on the dashboard, follow the certificate instructions, and enter the six-digit pairing code. On later visits, scan **Open remote**.

Open `START-HERE.html` for device-specific instructions. If Windows Firewall blocks the connection on your private network, run the included `Enable-Private-Network.cmd` as administrator. Install only the certificate generated by your own PC. Close the companion to stop control.

## Build from source

The Windows release includes the web interface inside the executable. You can also choose **Code → Download ZIP**, extract the entire folder, and run `START.cmd` beside the included `AirGlide.exe`. On Windows with Go 1.24 or later:

```powershell
cd source
go test ./...
go build -buildvcs=false -trimpath -o ..\AirGlide.exe .
```

See the build workflow for icon generation and release packaging.
